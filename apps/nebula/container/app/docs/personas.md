# Personas

The cast — every kind of person who uses this app — as a numbered procedure that re-creates them from nothing. Keyed on persona NAME, never on an id: identities are re-minted by every data wipe, so this file is what survives. Every persona is synthetic, on a reserved dead domain (`@example.com`, `*.test`, `*.invalid`), never a real address.

Write this when: the `define-the-cast` skill has elicited the cast, or a new kind of user appears in the conversation.

## The cast

Write this when: the personas are named. One line each — the name, what they do, what they must never see.

## The procedure

Every org-tree shape composes from four verbs — **mint** an identity, create a **node**, add an **edge** beneath another node, **grant** a persona a tier on a node. Write the steps in order so the same cast can be re-created after a wipe; a worked example, for a secret-santa app:

1. Mint `Sally <sally@example.com>` as the stand-in founder: admin on the root node and scopeAdmin at the `.dev` Star.
2. Create the node `lists`.
3. Add `example` beneath `lists`.
4. Mint `Gerry <gerry@example.com>`; grant Gerry `admin` on `example`.

Write this when: the cast is settled. Replace the example with this app's own steps.
