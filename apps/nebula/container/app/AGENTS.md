# Guidance for this app

Standing guidance for whoever builds this app — Nebula Studio's assistant on every turn, or any agent opened on a clone. Add to it; the platform's own guidance is read first and this file never subtracts from it.

Write this when: a participant states a convention ("no countdown timers", "always confirm before deleting"), corrects a mistake, or something non-obvious had to be learned the hard way. One line each, where it fits — conventions near the top, lessons where they belong.
