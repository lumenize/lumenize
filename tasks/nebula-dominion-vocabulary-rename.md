**Objective — every identifier that names dominion says `dominion`, and nothing else changes.** No behaviour moves, no claim changes shape, no predicate gains or loses an argument. A reviewer should be able to check this file's diff by reading names — ⚠️ **with one named exception, and it is bigger than it looks.** Type-check covers the **identifiers**. It covers **nothing inside a SQL string**, and it does not reach a second function's parameter that merely forwards into a renamed one. Those two classes are where this rename can break silently, and § *Phase 2* is where they are handled.

## Why this is its own file

**Because "renames are free" is exactly the belief that hides them inside a bigger diff.** The three files after this one each change real behaviour — a claim's shape, a route's guard, a mint's authorization. Renames landing in those diffs are indistinguishable from the behaviour changes at review time, and this repo has the receipt: the `isAdmin` → `scopeAdmin` sweep touched **66 files**, and two packages (`packages/auth`, `packages/mesh`) keep their own unrelated `isAdmin` that a repo-wide replace would have broken — **the mesh one silently**.

Two things it buys:

- **The reviewable property is stated and checkable:** nothing here changes what any code *does*. A diff hunk that changes control flow is a defect in this file, by definition. ⚠️ **That property is only as good as its instruments** — see § *Acceptance criteria*, where two greps were structurally blind to the symbol this file is named after.
- **It settles the vocabulary before anything designs against it.** [nebula-invite.md](nebula-invite.md) currently parks a naming decision — its wire field is `invitees[].isAdmin` while the column is `Memberships.scopeAdmin` — on the grounds that *"deciding it here would be designing this endpoint from another task's cleanup."* After this file the cleanup has landed and that decision costs one line.

## Context and current state

`isAdmin` → `scopeAdmin` already shipped 2026-08-07 (at rest and in flight, 66 files, type-check green). This file finishes the same job for the *verdict* names, which lagged.

The vocabulary itself is settled: **`dominion`** and **`passage`** are reserved terms defined in [ADR-015](../docs/adr/015-passage-and-dominion.md) § *Terminology*. They replaced `authority` and `admission` on 2026-08-09 because both general words carried four meanings apiece and the ambiguity had shipped real bugs. ⚠️ **`reach` is not their umbrella noun** — it stays a verb, and MUST NOT be used as a noun for either verdict.

⚠️ **No deploy happens between now and the pre-alpha wipe**, vitest creates fresh storage per run, and the `/live` harness `rmSync`s `.wrangler/state` by construction. 🚨 **`wrangler dev` run by hand does NOT — corrected 2026-08-11, the earlier claim that it did was false.** `apps/nebula`'s `dev` script is a bare `wrangler dev` with no reset and there is **844K of `.wrangler/state` on disk right now** ([nebula-pre-alpha.md](nebula-pre-alpha.md) § *The wipe is a CLOSING WINDOW*, item 5: *"the constraint stands that there is no deploy between the rewrite and the wipe"*). ⇒ **No storage anywhere will ever run pre-rename code against a post-rename schema**, which is why § *Phase 2* needs no migration and this file needs no wipe gate.

**Missing:** the guards and helpers are still named for the **bit** or for the **deleted general word**, while the predicate they delegate to is about to be named for the **verdict**. That gap is the translation the reader carries, and this layer is where a carried translation becomes a security hole.

## Design intent, constraints, and future state

### The three tiers govern which name a symbol gets

A **structural fact** gets a literal name · a **verdict** gets a reserved word · **data** keeps its field name. That is the rule; this file applies it only where doing so changes no behaviour.

⚠️ **Counts below are dated samples, not inventories** (`tasks/README.md` § *Inventories*) — re-run the greps rather than trusting them.

### Constraints

- **[ADR-015](../docs/adr/015-passage-and-dominion.md)** — the definition home for both reserved terms. This file does not amend it and does not exercise it; it adopts its vocabulary. ⚠️ **Ratification is Larry's ad-hoc call and is gated on nothing** — no phase here owns it, and none may.
- **[ADR-007](../docs/adr/007-shared-node-security-core.md)** — one predicate expresses the model. This file does not add or remove a caller; it renames the one that exists and deletes one pass-through wrapper.
- **`.claude/rules/coding-style.md` § *Guard naming*** — the durable home for the three-tier rule and the `require*` = THROWS / `*Guard` = RETURNS contract, moved there 2026-08-11 so it outlives these four task files. ⚠️ **Do not restate its argument here** — cite the section.
- ⚠️ **`packages/auth` and `packages/mesh` MUST NOT have their own `isAdmin` swept.** It is a *different* bit (auth's `Subjects` column, and a flat top-level claim mesh mints for auth's gate). A repo-wide replace breaks both, **the mesh one silently** — which is why the 2026-08-07 sweep was scoped by hand. ⚠️ **This is NOT "do not touch those packages"** — Phase 1 must touch one line of `packages/mesh`; see there.
- ⚠️ **The Data-plane's `admin` permission is NOT renamed.** It is one of a symmetric triple (`CHECK(permission IN ('admin','write','read'))`), so renaming it drags `resourceWrite` and `resourceRead` along for no gain. This file renames the **Registry-scope** bit's verdicts only.

## Decisions

| Decision | Rejected alternative — why |
|---|---|
| **The renames land in their own file, first** | Folding them into the behaviour changes — a rename inside a diff that also moves control flow is unreviewable as a rename, and this is a few hundred call sites of mechanical noise laid over the changes that must not be gotten wrong. |
| **`enforceScopeReach` → `requirePassage` lands HERE**, though its input changes later | Holding it until the input changes — the body already computes passage across both arms, so the new name is true on arrival, and holding it means the next file's diff carries a rename on its most load-bearing function. |
| **`require*` means THROWS, repo-wide; a step that RETURNS a `Response` is `*Guard`** | Keeping `enforce` vs `require` as the carrier — it points the wrong way (`require` throws in Solidity and in `assert`, and at every one of this repo's own `requireAdmin` / `requirePermission` sites) and would rename all of them to `enforce*` to say what `require*` already says. **Homed in `coding-style.md`**, because it binds code written long after these files archive. |
| **`requireDominionHere`, not `requireDominion`** | The bare form — dominion is a **two-place relation** (ADR-015), and this is the family's only object-less member: `requirePermission(nodeId, tier)` names its object, `hasDominionOver(access, node)` cannot be read without one. "Require dominion" is one word from *the bare bit is dominion*, the failure this rename exists to prevent. Today's JSDoc already compensates in prose (*"over the node this call is running on"*), which per `calibration.md` §5 **is** the rename signal — and the sibling [nebula-registry-route-guards.md](nebula-registry-route-guards.md) spells its operand out for exactly this reason. `Here` is fixed by construction (the callee instance from `callContext`), so it cannot be passed wrong. |
| **The column rename is a DDL EDIT IN PLACE — no migration, on either table** | A numbered `ALTER TABLE … RENAME COLUMN` entry. ⚠️ **Reversed 2026-08-11 once the premise was checked.** Three facts kill it: no deploy happens before the wipe; local and test storage are created from scratch; and `clear()` **replays the migration DDL inline** on every version-changing ontology install, so a rename entry would create the table with the old name and immediately rename it — **forever**. |
| **`accessAdmin` splits into `dominionOverHostAtSubscribe` (the column) and `hasDominionOverHost` (the parameter)** | One name for both — `AtSubscribe` asserts subscribe-time confinement, which `evaluatePermissions`' own JSDoc **disclaims** for its parameter. One name would stamp a false security claim, in the file whose thesis is that it settles the vocabulary. |
| **`#hasAdminOverScope` is deleted, not renamed** | Renaming the wrapper forward — it is a one-line pass-through to the shared predicate under the same name, with one caller. `calibration.md` §2: make the class impossible rather than carrying it. |
